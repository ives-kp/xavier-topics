🤔 什麼是賽局理論？

賽局理論研究的是：當你的決策會影響別人，別人的決策也會影響你時，應該怎麼選擇？

例如：

  • 🎯 和朋友決定去哪裡玩（他的選擇影響你的快樂）
  • 📚 班級決定要不要作弊（別人作弊會影響你的排名）
  • 🌍 各國決定要不要環保（別的國家污染會影響你）
  • 💼 企業決定降價還是漲價（競爭對手會跟著反應）

第一層：基礎直覺 🌱

📊 報酬矩陣：用表格看結果

博弈的結果可以用表格展示。表格的每一格代表一種選擇組合的結果。

例子：岔路口的選擇

Xavier和小王一起去旅遊，到了岔路口。一個向左是海邊（Xavier喜歡），一個向右是山區（小王喜歡）。他們必須一起去，不能分開。

報酬矩陣（數字越大越開心）：

Xavier \ 小王 選山區 選海邊
選海邊 💔 (0, 10) 😊 (10, 10) ✓
選山區 😐 (5, 5) 😞 (0, 0)

怎麼讀？

• 左邊的數字 = Xavier的滿意度

• 右邊的數字 = 小王的滿意度

• (10, 10) = 都去海邊，兩人都最開心

⚠️ 囚徒困境：為什麼會背叛？

囚徒困境是最經典的博弈：每個人的「最好選擇」導致「最差結果」。
警察抓到兩個嫌犯。分別關在不同房間，無法溝通。

警察跟每個人說：
• 如果你背叛對方（坦白），你就自由。對方坐牢10年。
• 如果你保持沉默（合作），都會這樣：
  - 你也沉默 → 都坐2年
  - 他背叛你 → 你坐10年，他自由

報酬矩陣（用年數，越少越好）：

我 \ 他 沉默 背叛
沉默 😊 (-2, -2) 最好 😞 (-10, 0)
背叛 😞 (-0, -10) 😐 (-5, -5) 現實
困境在哪裡？
無論對方選什麼，背叛都比沉默「對你個人」更好（坐監更少）。
但結果：都背叛(5年) 比 都沉默(2年) 還糟！

⚖️ 納許均衡：誰都不想改變

納許均衡 = 每個人都選了最好的策略，沒有人想改變自己的選擇。

在囚徒困境中：

✓ 納許均衡 = (背叛, 背叛) → (-5, -5)

為什麼？看著彼此都背叛了，我想改成沉默嗎？

不想！因為如果我沉默，他背叛的話我會-10年。

所以誰都不想改變。


❌ 另一個可能的結果 = (沉默, 沉默) → (-2, -2)

雖然更好，但不穩定！

如果我知道他沉默，我會背叛去搶0年。

納許均衡的結果 (-5, -5) 不是「最好」的，但是「最穩定」的。
這就是為什麼：儘管都環保更好，但人們還是污染。

第二層：博弈類型 🎭

🤝 協調博弈：雙贏就是均衡

不是所有博弈都像囚徒困境。有些博弈的最好結果反而就是均衡。

Xavier和小王計畫看電影。都看同一部最開心，各看各的沒人陪，最糟糕。

報酬矩陣：

Xavier \ 小王 科幻片 恐怖片
科幻片 😊 (10, 10) ✓ 😞 (0, 0)
恐怖片 😞 (0, 0) 😊 (10, 10) ✓

有兩個納許均衡！

✓ (科幻, 科幻) → (10, 10)

✓ (恐怖, 恐怖) → (10, 10)

協調博弈的困難：不是「合作不合作」，而是「選哪個合作方案」。
例如：為什麼全世界開車有的靠左有的靠右？因為都有道理，但不能混。

⚔️ 零和博弈：只能分勝負

零和博弈 = 你贏的東西完全來自我的輸。總和永遠是零。

例子：石頭布剪刀

我 \ 你 石頭 布 剪刀
石頭 0, 0 -1, +1 +1, -1
布 +1, -1 0, 0 -1, +1
剪刀 -1, +1 +1, -1 0, 0
在零和博弈中，沒有「雙贏」的可能。
所以最好的策略是：隨機選擇，讓對手無法預測。

第三層：演化博弈論 🦅🕊️

📖 鷹鴿故事：最經典的演化博弈

一個鳥類社群中，有兩種策略：

🦅 鷹策略：激進、好鬥，搶食物時猛烈攻擊
🕊️ 鴿策略：溫和、讓步，看到對手就逃跑

他們搶食物。每次搶奪有不同結果...

一次搶奪的報酬：

遇到 \ 我是 鷹 鴿
鷹 ⚔️ 0 (互相鬥，都受傷) 😞 -1 (被搶)
鴿 😋 4 (搶到全部) 😐 2 (分享)

關鍵發現：

• 🦅 遇 🕊️ → 🦅 大贏(4分)

• 🦅 遇 🦅 → 都損失(0分，互相傷害)

• 🕊️ 遇 🕊️ → 都分享(2分)

📊 種群演化：代代相傳

現在想像一個有100隻鳥的社群。開始時：99隻鴿，1隻鷹。

第1代會怎樣？
• 🦅 很爽：到處搶 🕊️，報酬4分 × 很多次
• 🕊️ 被搶：經常吃虧，報酬-1分
→ 🦅 長得快，🕊️ 死得多

但是...

第5代會怎樣？
• 🦅 很多了，開始互相遇到
• 🦅 遇 🦅 → 互相打架，報酬0分（糟糕！）
• 🕊️ 雖被搶，但活著 → 報酬2分
→ 🦅 減少，🕊️ 增加

最後呢？

到某個時間點，🦅 和 🕊️ 達到一個「平衡」。
例如：30隻鷹，70隻鴿。

在這個比例下：
• 🦅 的平均報酬 ≈ 🕊️ 的平均報酬
• 誰都無法「單靠增加數量」來改進

這就是「進化穩定策略 (ESS)」

🔢 計算：進化穩定比例

在鷹鴿博弈中，可以用數學計算出穩定的比例。

如果鷹的報酬 = 4(1 - p)
鴿的報酬 = 2 - 3p

其中 p = 鷹的比例

均衡點：4(1 - p) = 2 - 3p
→ p = 0.4 (40%)
所以穩定的鷹鴿比例是：40% 鷹，60% 鴿。
不管初始比例多少，最後都會演化到這個點。

📈 和指數律的連結

你在數學課學的指數律，在這裡出現了！

如果鷹的報酬高於鴿，鷹會以指數增長：
N(t) = N₀ × r^t

其中 r ≈ 1.2 (增長率)

• 第5代：N₀ × (1.2)^5
• 第10代：N₀ × (1.2)^10

🌍 現實應用

🧬 抗生素耐藥性

細菌對藥物敏感 = 🕊️
細菌對藥物耐藥 = 🦅

使用抗生素 → 敏感菌死 → 耐藥菌繁殖 → 最後全是耐藥菌

🎓 班級作弊率

認真讀書 = 🕊️
偷懶作弊 = 🦅

不是「全部作弊」或「全部認真」，而是某個混合比例穩定
