第一階段　數感基礎：讓數字有意義

這個階段的四個任務看起來主題不同，但底層都在問同一件事：「數字代表什麼？」負數有方向，質數有結構，RGB 是比例，隨機有規律。這個階段建立的是「數感」——對數字的直覺。

1-1

負數、溫標與絕對零度

對應學習單：1-1 溫度換算器
負數 溫度換算 熱力學第三定律（延伸）
核心概念

負數是「方向」，不是「少了什麼」

在日常生活裡，負數最自然的出現是溫度。0°C 不代表「沒有溫度」，而是一個我們定義的基準點（水的冰點）。比這個基準點冷，就是負數；比它熱，就是正數。

這說明負數的本質：它是數線上相對於基準點的方向，不是「缺少」的意思。同樣的道理也出現在：樓層（B1 = 地下一層）、海拔（海平面以下）、帳戶餘額（負債）。

三種溫標：為什麼有這麼多種？
攝氏 ↔ 華氏換算
°F = °C × 9/5 + 32
9/5 是刻度間距的比值：華氏從冰點到沸點有 180 格，攝氏有 100 格，所以比值是 180/100 = 9/5。
+32 是因為華氏的冰點定在 32°F，而不是 0°F。
攝氏 ↔ 克氏（絕對溫標）換算
K = °C + 273.15
克氏溫標的 0 K 是物理上真正的最低溫（絕對零度），等於 −273.15°C。這是分子停止熱運動的理論下限。克氏的刻度大小和攝氏完全相同，只是起點不同。
推導：為什麼 −40°C = −40°F？
找出攝氏和華氏相等的那個點
1
設攝氏和華氏相等，令 °C = °F = x
x = x × 9/5 + 32
2
移項整理
x − 9x/5 = 32　→　−4x/5 = 32
3
解出 x
x = 32 × (−5/4) = −40
所以 −40°C = −40°F，是唯一一個攝氏和華氏讀數相同的溫度。
延伸：絕對零度能到達嗎？
熱力學第三定律（延伸知識）

熱力學第三定律告訴我們：任何物質的溫度可以無限接近絕對零度（0 K），但永遠無法真正到達。這不是技術上的限制，而是物理定律本身。

  • 目前人類實驗室達到的最低溫度是約 0.000000001 K（10⁻⁹ K），比外太空（約 2.7 K）還要冷得多
  • 在接近絕對零度時，一些奇特的量子現象會出現，例如「玻色-愛因斯坦凝聚態」——原子幾乎完全靜止，集體表現得像一個量子態
  • 絕對零度是熵（disorder，混亂程度）為零的狀態
換個方式想

攝氏溫標就像是用海平面當 0 的地圖：水面以上是正，水面以下是負。克氏溫標則是重新畫了地圖，把宇宙中最冷的地方定為 0——這樣所有溫度都是正數，物理計算方便得多。

練習題
計算 題目 1
人體正常體溫是 37°C。請計算：（a）換成華氏是幾度？（b）換成克氏是幾 K？
（a）°F = 37 × 9/5 + 32 = 66.6 + 32 = 98.6°F　　（b）K = 37 + 273.15 = 310.15 K
體溫 98.6°F 就是為什麼美國人用這個數字判斷發燒。
推理 題目 2
火星的平均氣溫約為 −60°C。請計算換成克氏是幾 K？並說明為什麼科學家更常用克氏而不是攝氏來描述行星溫度。
提示：想想負數在計算上的麻煩。
K = −60 + 273.15 = 213.15 K
使用克氏的原因：克氏沒有負數，計算能量、壓力等物理量時不會出現「負溫度」造成的錯誤。例如，氣體的壓力和體積的乘積 PV 正比於溫度（克氏），如果溫度是負數，計算結果就沒有意義。
延伸思考 題目 3
如果有人設計了一種新的溫標「X 氏」，規定水的冰點是 100°X，沸點是 0°X（剛好和攝氏顛倒），那麼人體體溫 37°C 換成 X 氏是幾度？請推導換算公式。
°X = 100 − °C　所以 37°C = 63°X
推導：X 氏的刻度大小和攝氏相同（同樣是 100 格），只是方向顛倒。冰點在攝氏是 0，在 X 氏是 100，所以加上一個 100 的偏移，再把方向反過來：°X = 100 − °C。
1-2

因數、質數與數論基礎

對應學習單：1-2 質數篩選器
因數與倍數 質數的定義與性質 質數在密碼學的應用（延伸）
核心概念

質數：數字世界的「原子」

化學有元素週期表，所有物質都由元素組成。數論也有類似的東西：所有大於 1 的整數，都可以分解成質數的乘積。質數是數字世界的基本組成單位。

質數的定義：只有 1 和它自己兩個因數的正整數（且大於 1）。1 不是質數，因為它只有一個因數。

算術基本定理
每個大於 1 的整數，都能唯一地寫成質數的乘積
例如：360 = 2³ × 3² × 5　　100 = 2² × 5²　　17 = 17（本身就是質數）
這個分解方式只有一種（不考慮順序），稱為「唯一分解定理」。
為什麼判斷質數只需要試到 √n？
一個重要的省力技巧
1
假設 n 不是質數，那麼它有一個因數 a，使得 n = a × b，其中 a ≤ b
2
因為 a ≤ b，所以 a × a ≤ a × b = n，意思是 a ≤ √n
換句話說：如果 n 有因數，其中較小的那個一定不超過 √n
3
結論：只需要試除 2 到 √n，如果都沒有整除，n 就是質數
if n % i == 0 for any i in range(2, int(n**0.5)+1) → not prime
這讓程式快很多：判斷 10,000 是否是質數，只需要試到 100，不是 10,000 次
質數有多少個？

質數有無限多個（歐幾里得的證明，約 300 BC）

假設質數只有有限個，設它們是 p₁, p₂, ..., pₙ。考慮數字 N = p₁ × p₂ × ... × pₙ + 1。N 除以任何已知的質數，餘數都是 1，所以 N 不能被任何已知質數整除——但每個大於 1 的數都必須有質因數，這個質因數就是一個新的質數。矛盾！所以質數有無限多個。

這是人類最古老的數學證明之一，距今超過 2300 年，卻至今仍然完美。

延伸：質數在密碼學的應用
RSA 加密（你的 HTTPS 就是這個）

每次你看到瀏覽器網址欄的「鎖頭」，背後用的就是質數。RSA 加密的核心邏輯：

  • 把兩個超大質數相乘很容易（電腦瞬間完成）
  • 但把乘積反過來分解回兩個質數，卻極度困難——即使是全世界最快的電腦，也需要數十億年
  • 這個「正向容易、逆向困難」的不對稱性，就是密碼學的基礎
  • 現代加密用的質數大約有 1024 到 4096 個二進位位元——一個幾百位數的質數
換個方式想

質數就像樂高積木中的最小單元——一個 1×1 的小方塊。任何複雜的積木造型都可以拆解成這些小方塊。數字世界的「造型」（所有整數）都可以拆解成「小方塊」（質數）。但注意：積木可以相同方塊用多次，數字也可以。

練習題
計算 題目 1
不用電腦，手動判斷以下數字是否是質數：97、91、101。說明你的判斷過程。
提示：97 的平方根約 9.8，91 的平方根約 9.5，所以只需試到 9。
97：是質數　　91：不是質數（91 = 7 × 13）　　101：是質數
97：試除 2,3,5,7（2→不整除，3→不整除，5→不整除，7→不整除），所以是質數。
91：7 × 13 = 91，所以不是質數。
101：試除 2,3,5,7（都不整除），√101 ≈ 10.05，所以只需試到 10，101 是質數。
分析 題目 2
360 = 2³ × 3² × 5。請問 360 共有幾個因數？（提示：不需要一個一個列出來）
提示：若 n = pᵃ × qᵇ × rᶜ，則因數個數 = (a+1)(b+1)(c+1)
360 的因數個數 = (3+1)(2+1)(1+1) = 4 × 3 × 2 = 24 個
為什麼這個公式成立？因為每個因數由選擇 2 用幾次（0到3，共4種）× 3 用幾次（0到2，共3種）× 5 用幾次（0到1，共2種）組合而成。
思考 題目 3
孿生質數是指差值為 2 的一對質數，例如 (3,5)、(11,13)、(17,19)。數學家猜測孿生質數有無限多對，但至今沒有人能證明這件事。你覺得：如果質數有無限多個，孿生質數就一定也有無限多對嗎？為什麼？
不一定。質數有無限多個，不代表孿生質數也有無限多對。
類比：正整數有無限多個，但「完全平方數」（1, 4, 9, 16...）也有無限多個，但兩者「密度」不同。質數會越來越稀疏，所以相鄰質數之間的間距可能越來越大，孿生質數是否一直存在，是數學史上最著名的未解問題之一（孿生質數猜想）。2013 年，張益唐證明存在無限多對質數，其差值小於 7000 萬，這是一個里程碑，但還不是最終答案。

比例、光的三原色與色彩科學

對應學習單：1-3 RGB 調色盤
比與比例 光的加法混色 人眼的色覺原理（延伸）
核心概念

光的三原色 vs 顏料的三原色：為什麼不一樣？

你學過的顏料三原色（紅、黃、藍）和螢幕的 RGB（紅、綠、藍）是不同的。原因是混合方式不同：

顏料是「減法混色」：顏料吸收某些光，剩下的才反射到你眼睛。混越多，吸收越多，越接近黑色。

光（螢幕）是「加法混色」：光是自己發出的，混越多，越亮，三種全開就是白色（255, 255, 255）；三種全關就是黑色（0, 0, 0）。

RGB 的比例結構
顏色 = (R/255, G/255, B/255)
每個通道 0–255，共 256 個值（2⁸，8 個二進位位元）。三個通道組合可以表示 256³ = 16,777,216 種顏色（約 1670 萬色）。這就是為什麼螢幕說「支援 16 百萬色」。
比例如何決定顏色感覺
RGB 值比例特性顏色原因
(255, 0, 0)R 獨大純紅只有紅光
(0, 255, 0)G 獨大純綠只有綠光
(0, 0, 255)B 獨大純藍只有藍光
(255, 255, 0)R=G，無B黃色紅+綠=黃（加法混色！）
(255, 0, 255)R=B，無G洋紅紅+藍=洋紅
(128, 128, 128)三者相等（非零）灰色等比例混合
(255, 165, 0)R最大，G中，無B橘色偏紅的黃
延伸：為什麼人眼看得到顏色？
視錐細胞與色覺（色彩生物學）

人的視網膜有三種視錐細胞，分別對長波（紅）、中波（綠）、短波（藍）的光最敏感。所有顏色的感知，都是這三種細胞的興奮程度組合而成——這和 RGB 的三通道結構完全對應，不是巧合。

  • 色盲的人通常缺少某一種視錐細胞，例如紅綠色盲（最常見）是長波和中波視錐細胞的色素相似
  • 有些鳥類、蝦類有 4 種甚至 16 種視錐細胞，看到的色彩世界比人類豐富得多
  • 狗只有 2 種視錐細胞（類似人類的藍色和黃色），所以看到的世界像「雙色色盲」
練習題
計算 題目 1
顏色 (200, 100, 50) 的三個通道各占最大值（255）的百分比是多少？這個顏色偏暖還是偏冷？
R: 200/255 ≈ 78%　　G: 100/255 ≈ 39%　　B: 50/255 ≈ 20%　　偏暖色（R 遠大於 B）
這個顏色 R 最高，B 最低，是一種橘棕色。偏暖是因為紅色比藍色強很多。
推理 題目 2
如果一個 RGB 顏色三個值完全相同（例如 (100, 100, 100)），它看起來一定是灰色嗎？當三個值都是 0 和 255 時分別是什麼顏色？
是的，三個值相同時一定是灰色（或黑/白）。(0,0,0) = 黑色，(255,255,255) = 白色
灰色是「中性色」，意思是三種光的比例完全相等。不同亮度的灰色只是三個值同樣大小不同：(50,50,50) 深灰，(200,200,200) 淺灰。
創意 題目 3
台灣的太平洋日出，你覺得日出時天空的橘紅色大約是什麼 RGB？天空由深藍轉橘紅，這個「過渡」在 RGB 數值上會怎麼變化？（用語言描述趨勢，不用算精確值）
日出橘紅大約：(255, 120, 30) 左右。趨勢：B 從高到低，R 從中低到高，G 先降後升。
天空漸變的 RGB 趨勢：深藍夜空 (10, 10, 80) → 黎明深紫 (80, 30, 100) → 橘紅日出 (255, 100, 30) → 日出後金黃 (255, 200, 80) → 白天藍天 (100, 150, 255)。B 通道先高後低，R 通道從低到高，G 通道在日出時最低（橘紅色沒什麼綠）。
1-4

隨機、機率與資訊量

對應學習單：1-4 猜數字遊戲
隨機數 二元搜尋策略 資訊熵（延伸）
核心概念：最聰明的猜法

每次都猜中間：二元搜尋（Binary Search）

猜 1–100 的數字，如果你每次都猜「剩餘範圍的中間值」，最多幾次能猜到？答案是 7 次。因為每次猜錯都能把範圍砍半：100 → 50 → 25 → 13 → 7 → 4 → 2 → 1。

這個策略叫「二元搜尋」，是電腦科學中最重要的演算法之一。

最多需要幾次？
最多次數 = ⌈log₂(n)⌉
n = 範圍大小（例如 100）。log₂(100) ≈ 6.64，取上整是 7。
意思是：每次可以消除一半的可能性，所以需要「把 n 減半多少次才到 1」，答案就是以 2 為底的對數。
電腦的隨機數是真的隨機嗎？

偽隨機數（Pseudo-random）

Python 的 random.randint() 產生的不是「真正的隨機」，而是用數學公式計算出來的「偽隨機數」。它看起來隨機，但如果你知道起始種子（seed），就能完全預測。

真正的隨機來自物理：例如用放射性衰變的時間、電路噪音、甚至大氣噪音來產生隨機數。網站 random.org 就是用大氣噪音。

延伸：資訊量與熵
資訊理論（Claude Shannon，1948）

猜數字遊戲可以用「資訊量」來理解：每次得到「太大」或「太小」的答覆，你獲得了 1 bit 的資訊（消除了一半的可能性）。

  • 猜 1–100：需要約 log₂(100) ≈ 6.64 bits 才能確定答案
  • 猜 1–1000000：需要約 log₂(1000000) ≈ 20 bits
  • 這就是為什麼 8 位元（8 bits）能表示 256 個值（2⁸ = 256）——8 次二元選擇
  • Shannon 的資訊熵理論是現代通訊、壓縮（ZIP）、網路的基礎
練習題
計算 題目 1
猜 1–1000 的數字，用二元搜尋策略，最多需要幾次？
最多 10 次。log₂(1000) ≈ 9.97，取上整 = 10。
驗證：1000 → 500 → 250 → 125 → 63 → 32 → 16 → 8 → 4 → 2 → 1，剛好 10 步。
策略 題目 2
在猜數字遊戲中，如果你知道對手「偏好猜比較大的數」，你應該怎麼調整你「想的數字」的策略？這是否公平？
如果對手偏好猜大數，你應該多想小的數，讓他花更多次猜到。這不違反規則，但利用了對手的偏見。
這是博弈論的基礎：了解對手的策略傾向，然後選擇讓對手代價最高的策略。真正的「隨機」（每個數都等機率）是最難被對手利用的策略，這叫「混合策略納什均衡」。
第二階段

第二階段　代數與方程式：讓未知數說話

代數的核心是：用符號（x）代表我們不知道的東西，然後根據它滿足的條件找出它的值。這個思路本身就是科學方法的縮影——從觀察到的結果，推斷看不見的原因。

2-1

一元一次方程式的本質

對應學習單：2-1 方程式求解器
移項與等量公理 邊界情況 線性代數的起點（延伸）
核心概念

方程式是一個「平衡」的表達

等號的意思是：左邊和右邊的值完全相等。方程式描述的是一種「約束關係」——x 必須是某個值，才能讓這個平衡成立。

解方程式的每一步，都必須對等號兩邊做「完全相同的事」，才不會破壞平衡。這個原則叫「等量公理」（等式兩邊加、減、乘、除同一個數，等式仍成立）。

為什麼 ax + b = 0 的解是 x = −b/a？
1
目標：把 x 單獨留在一邊
ax + b = 0
2
兩邊都減去 b（等量公理）
ax = −b
3
兩邊都除以 a（假設 a ≠ 0）
x = −b/a
如果 a = 0，就不能除，這就是為什麼要特別處理 a = 0 的情況
特殊情況：無解 vs 無限多解

當 a = 0 時發生什麼？

方程式變成 0 × x + b = 0，也就是 b = 0。這和 x 完全無關。

如果 b = 0：方程式是 0 = 0，任何 x 都成立 → 無限多解。

如果 b ≠ 0：方程式是 b = 0，這是假的 → 無解（矛盾）。

延伸：從一個方程式到多個
聯立方程式與矩陣（線性代數的入口）

一個方程式解一個未知數。兩個方程式可以解兩個未知數（聯立）。n 個方程式可以解 n 個未知數——這就是「線性代數」和「矩陣」要解決的問題。

  • 工程師用聯立方程式計算橋樑的受力
  • 經濟學家用它分析市場供需
  • AI 的神經網路，本質上是解一個超大的聯立方程式系統（數億個未知數）
  • Google 的 PageRank（網頁排名）演算法，是解一個包含幾十億個未知數的矩陣方程

為什麼方程式「除以 a」的步驟需要限制「a ≠ 0」？如果允許除以 0，會發生什麼事？試著用一個具體的例子說明。
除以 0 是未定義的，它會導致「任何數都成立」的矛盾。

坐標系、直線方程式與斜率

對應學習單：2-2 第一張圖表
坐標系 斜率的物理意義 解析幾何（延伸）
核心概念

笛卡兒坐標系：把幾何翻譯成代數

17 世紀，笛卡兒（René Descartes）發明了坐標系。這個發明的偉大之處在於：它把「形狀」這個視覺的東西，翻譯成了「方程式」這個計算的東西。從此幾何問題可以用代數來解，代數問題可以用幾何來理解——兩個數學分支互相幫助。

直線方程式（斜截式）
y = kx + b
k = 斜率：每往右移動 1，y 的變化量。k > 0 往右上，k < 0 往右下，k = 0 水平線。
b = y 截距：直線和 y 軸的交點的 y 坐標（x = 0 時，y = b）。
斜率的計算與意義
斜率 = 「上升量 / 水平移動量」
1
取直線上兩個點：(x₁, y₁) 和 (x₂, y₂)
k = (y₂ − y₁) / (x₂ − x₁)
2
斜率代表「x 每增加 1，y 增加多少」
如果斜率 k = 3，意思是每往右走 1，就往上走 3
3
斜率是變化率——這個概念在物理、經濟、科學裡無處不在
速度 = 距離/時間（d-t 圖的斜率）；加速度 = 速度/時間（v-t 圖的斜率）；利率 = 利息/本金
延伸：解析幾何的力量
笛卡兒的革命：幾何 = 代數
  • 兩條直線的交點，就是解聯立方程式的解
  • 圓的方程式：x² + y² = r²（所有距離原點 r 的點）
  • 拋物線的方程式：y = ax²（這是下一個階段的核心）
  • GPS 定位：用你到三個衛星的距離（三個球面方程式），解出你的位置坐標
  • 電腦圖形學：每個 3D 模型都是坐標點的集合，動畫是坐標隨時間的方程式
練習題
計算 題目 1
過點 (2, 5) 和 (6, 13) 的直線，斜率是多少？寫出直線方程式。
k = 2，方程式：y = 2x + 1
斜率：k = (13−5)/(6−2) = 8/4 = 2。代入點 (2,5)：5 = 2(2) + b → b = 1。所以 y = 2x + 1。
應用 題目 2

d = 30t + 10　　斜率 30 = 速度（m/s）　　截距 10 = 初始位置（m）
這個式子和 y = kx + b 完全相同結構：d 是 y，t 是 x，速度 v = 30 是斜率 k，初始位置 d₀ = 10 是截距 b。
思考 題目 3
斜率為 0 的直線是水平線（y = b）。斜率「無限大」的直線又是什麼？它能用 y = kx + b 的形式寫嗎？
斜率無限大的直線是垂直線，形式是 x = c（常數），不能用 y = kx + b 表達。
垂直線上，x 固定不變，y 可以是任何值。它的斜率是「任意 y 的變化 / 0 的 x 變化」= 除以 0 = 無定義。這就是 y = kx + b 這個形式無法表達垂直線的原因——直線方程式有兩種形式：斜截式（無法表達垂直線）和一般式 ax + by + c = 0（可以表達所有直線）。

不等式：描述「範圍」而非「點」

對應學習單：2-3 不等式視覺化
不等號方向 解集合 線性規劃（延伸）
核心概念

方程式 vs 不等式：點 vs 區域

方程式的解是「特定的值」（一個點或有限個點）。不等式的解是「一個範圍」——所有讓不等式成立的 x 值的集合，叫做解集合。

最重要的規則：除以負數要翻轉
如果 a < b，且 c < 0，則 ac > bc
直觀理解：在數線上，−2 在 2 的左邊，所以 −2 < 2。但乘以 −1 後，2 在 −2 的左邊，所以 2 > −2。乘以負數讓數線上的「左右」關係翻轉。
解 −3x + 6 > 0
1
移項
−3x > −6
2
兩邊除以 −3（負數！不等號翻轉）
x < 2
解集合：所有小於 2 的 x 值，在數線上是從 2 往左的射線（不包含 2）
延伸：線性規劃——最大化與最小化
不等式的大用途

現實中的問題常常是「在某些限制條件下，找出最好的方案」。這類問題叫線性規劃（Linear Programming）。

  • 工廠生產：原料有限（不等式限制），如何安排生產讓利潤最大？
  • 飲食計畫：卡路里不超過 2000（不等式），蛋白質至少 60g（不等式），如何選擇食物讓花費最少？
  • 物流配送：每輛車限重 5 噸（不等式），如何安排讓運輸成本最低？
  • 1947 年，George Dantzig 發明了單純形法（Simplex Method）來解這類問題，至今仍是工業界最重要的最佳化工具之一

第三階段

第三階段　函數與運動：數學如何描述物理世界

最重要的橋樑：一次函數 y=kx+b 和等速運動 d=vt 是同一件事。掌握這個連結，你就理解了「函數」的本質——它不是抽象的符號遊戲，而是描述事物如何變化的語言。

3-1

一次函數、速度與變化率

對應學習單：3-1 速度比較圖
一次函數 y=kx+b 等速直線運動 導數的直觀（延伸）
核心概念：數學和物理的同一件事
數學語言物理語言圖形意義
y = kx + bd = vt + d₀直線
x（自變數）t（時間）橫軸
y（因變數）d（距離）縱軸
k（斜率）v（速度）直線的傾斜程度
b（截距）d₀（初始位置）直線和縱軸的交點
速度的定義
v = Δd / Δt = (d₂ − d₁) / (t₂ − t₁)
速度是距離對時間的「變化率」。在 d-t 圖上，這就是斜率。
平均速度 = 總距離 / 總時間
瞬時速度 = 在某一時刻的速度（需要微積分的概念）
延伸：斜率就是導數

在等速運動中，速度是固定的——d-t 圖是直線，斜率到處都一樣。但如果運動不是等速的呢？例如汽車在加速？

  • 這時 d-t 圖是曲線，不同位置的斜率不同
  • 「某一點的斜率」就是微積分中的「導數」——它告訴你在那個瞬間，速度是多少
  • 牛頓和萊布尼茲在 17 世紀發明微積分，就是為了計算這種「瞬時變化率」
  • 現代物理、工程、AI 的優化算法，都建立在導數的概念上

3-2

正比、反比與功的概念

對應學習單：3-2 正反比互動模擬
正比關係 y = kx 反比關係 y = k/x 功與能量（物理）
正比 vs 反比：形狀的對比
類型數學形式圖形形狀物理例子
正比y = kx（k > 0）過原點的直線等速：距離 ∝ 時間
反比y = k/x雙曲線（L 形曲線）固定功：力 ↑ 則位移 ↓
功的定義
W = F × d
W = 功（焦耳，J）　F = 力（牛頓，N）　d = 位移（公尺，m）
功是「把東西移動一段距離」所花費的能量。固定功 W 時，F 和 d 成反比：力越大，能推的距離越短。

為什麼反比曲線永遠不會碰到坐標軸？

y = k/x 中，x 無論多大，y 都是正數（趨近 0 但不等於 0）；x 無論多小（正數），y 都趨近無限大但不是無限大。曲線永遠在靠近坐標軸卻永遠碰不到，這樣的線叫做「漸近線」。

現實意義：力絕對不可能是 0，否則功 W = 0 × d = 0；位移也不可能是 0，否則你沒有移動任何東西。所以物理上，力和位移都必須大於 0。

練習題
計算 題目 1
你用 50 牛頓的力推一個箱子走了 4 公尺。（a）做了多少焦耳的功？（b）如果換用 25 牛頓的力做同樣的功，需要走多遠？
（a）200 焦耳　（b）8 公尺
（a）W = 50 × 4 = 200 J
（b）200 = 25 × d → d = 8 公尺（力減半，距離加倍，反比關係）
比較 題目 2
y = 2x 和 y = 2/x 在 x = 1, 2, 4, 8 時各自的 y 值是多少？填入表格並說明兩者的差異。
正比 y=2x：2, 4, 8, 16（x 加倍，y 加倍）。反比 y=2/x：2, 1, 0.5, 0.25（x 加倍，y 減半）
正比：x 乘以常數因子，y 也乘以同樣因子（同向）。反比：x 乘以常數因子，y 除以同樣因子（反向）。這就是「正比」和「反比」名稱的來源。
3-3

拋體運動：二維的運動分析

對應學習單：3-3 拋體模擬動畫
運動分解 重力加速度 最佳射程角度的推導（延伸）
核心概念：把二維運動拆成兩個一維

伽利略的天才洞見（約 1600 年）

拋體同時做兩種運動：水平方向的等速運動，和垂直方向的加速運動。這兩個方向完全獨立，互不影響。把它們分開分析，各自都很簡單；合在一起就得到美麗的拋物線。

拋體運動的兩個方向
x = v₀cos(θ)·t　　　y = v₀sin(θ)·t − ½gt²
v₀ = 初速度　θ = 拋出角度　g = 9.8 m/s² = 重力加速度
水平：等速，速度分量 v₀cos(θ) 不變
垂直：初速 v₀sin(θ) 往上，但重力加速度 g 往下減速，再反向加速
推導：為什麼 45° 射程最遠？
1
落地時 y = 0，解出飛行時間 T
0 = v₀sin(θ)·T − ½gT² → T = 2v₀sin(θ)/g
2
代入水平距離公式
R = v₀cos(θ) × T = v₀cos(θ) × 2v₀sin(θ)/g = v₀²sin(2θ)/g
3
sin(2θ) 在 2θ = 90° 時最大，即 θ = 45° 時射程最遠
當 θ 和 90°−θ 是互補角時，sin(2θ) 相同，所以 30° 和 60° 的射程相等
延伸：為什麼現實中最佳角度不一定是 45°？
空氣阻力、地球曲率與實際彈道
  • 空氣阻力：越快越費力，所以高速拋體（如炮彈、棒球）的最佳角度低於 45°，大約 35°–40°
  • 高差：如果落點比出發點低（例如從山頂投擲），最佳角度也低於 45°
  • 地球曲率：對於遠程導彈，地球是圓的，彈道需要用更複雜的方程式（考慮地球半徑）
  • 網球發球：需要球越過球網（限制 y 高度），所以最佳角度完全不同，球員通常以幾乎水平的角度發球
練習題
計算 題目 1

（a）R ≈ 40.8 m　（b）H ≈ 10.2 m　（c）T ≈ 2.89 秒
（a）R = v₀²sin(2×45°)/g = 400×1/9.8 ≈ 40.8 m

比較 題目 2
以相同初速度，30° 和 60° 的射程為什麼相同？用 sin(2θ) 的性質說明。
因為 sin(2×30°) = sin(60°) = sin(120°) = sin(2×60°)
R = v₀²sin(2θ)/g。2×30° = 60°，2×60° = 120°。sin(60°) = sin(180°−60°) = sin(120°)，所以兩者相等。一般規律：θ 和 90°−θ（互餘）的射程永遠相同。
應用 題目 3

R = v₀²sin(2θ)/g。v₀ 和 θ 相同時，R 和 g 成反比。月球/地球 = g地球/g月球 = 9.8/1.6 ≈ 6.1。月球上球飛的距離是地球的 6 倍多，這就是為什麼太空人在月球能輕鬆打出超遠高爾夫球。
第四階段

第四階段　二次關係：曲線比直線更接近真實

當 y 和 x² 成正比，圖形就從直線變成拋物線。重力造成的所有運動都遵循二次關係。同一條數學曲線，描述了許多不同的物理現象。

4-1

自由落體、重力加速度與二次函數

對應學習單：4-1 自由落體計算器
等加速運動 平方根的幾何意義 為什麼重的物體不會落得更快（延伸）
核心概念

重力讓速度均勻增加：等加速運動

在沒有空氣阻力的情況下，所有物體（無論輕重）以相同的加速度 g ≈ 9.8 m/s² 向下加速。每過一秒，速度增加 9.8 m/s。

因為速度在增加，物體在第 1 秒走的距離，比第 2 秒少，比第 3 秒更少……這種「越來越快」的累積，就是 t² 出現的原因。

自由落體的核心公式
h = ½gt²　　→　　t = √(2h/g)
h = 落下高度（m）　g = 9.8 m/s²　t = 落地時間（秒）
落地速度：v = gt = √(2gh)（與質量完全無關！）
為什麼 h = ½gt²？（從加速度推導）
1
加速度的定義：每秒速度增加 g
v = g × t（從靜止開始）
2
距離 = 平均速度 × 時間（初速 0，末速 gt，平均是 gt/2）
h = (gt/2) × t = gt²/2 = ½gt²
3
直觀理解：前 t 秒的平均速度是 gt/2，乘以時間 t 得到距離
這個 ½ 就是梯形面積公式（v-t 圖下的三角形面積）
v-t 圖：速度從 0 線性增加到 gt。三角形的面積就是落下的距離 h = ½gt²
延伸：為什麼重的物體不落得更快？
伽利略推翻亞里斯多德（約 1590 年）

亞里斯多德認為重的東西落得更快（這個「常識」流傳了 2000 年）。伽利略用邏輯反駁了它：

  • 假設重球比輕球落得快。把它們綁在一起，輕球「拖慢」重球，應該比重球慢、比輕球快——但綁在一起比兩顆都重，應該更快。矛盾！
  • 唯一解決矛盾的方式：重量不影響落體速度，所有物體落得一樣快
  • 伽利略在比薩斜塔的實驗（可能是傳說），以及後來在真空中的羽毛和保齡球實驗，都驗證了這個結論
  • 牛頓後來解釋：重力 F = mg，但加速度 a = F/m = mg/m = g，質量剛好消掉了

二次函數、頂點與最大值問題

對應學習單：4-2 升級版拋體模擬

核心概念

拋物線的三種形式

二次函數的圖形叫拋物線。它有一個最高點（a < 0）或最低點（a > 0），叫頂點。三種常用的寫法，各有不同的好處：

形式形式說明直接可讀的資訊
標準式y = ax² + bx + cy 截距 = c
頂點式y = a(x − h)² + k頂點 = (h, k)
因式分解式y = a(x − r₁)(x − r₂)x 截距 = r₁, r₂
頂點座標公式（從標準式推導）
頂點 x 坐標 = −b/(2a)　　頂點 y 坐標代入得到
對稱軸：x = −b/(2a)（拋物線左右對稱的中心線）
在拋體模擬中：y 對 t 的函數 y = v₀sin(θ)·t − ½gt²，頂點 t = v₀sin(θ)/g，就是最高點時間。
為什麼 30° 和 60° 的軌跡形狀不同但射程相同？
1
30° 的軌跡：低平寬廣（初速的水平分量大，垂直分量小）
2
60° 的軌跡：高峻窄長（初速的垂直分量大，水平分量小）
3
雖然形狀不同，射程相同——因為 sin(2×30°) = sin(2×60°) = sin(60°) = √3/2
兩條不同形狀的拋物線，有相同的起點和終點（落地點），但頂點高度完全不同

計算 題目 1

頂點 (2, 5)，對稱軸 x = 2
頂點 x = −b/(2a) = −8/(2×(−2)) = −8/(−4) = 2。頂點 y = −2(4) + 8(2) − 3 = −8 + 16 − 3 = 5。

探究設計：科學方法的結構

對應學習單：4-3 探究主題提案

什麼是科學探究？

科學不是找「正確答案」，是找「最好的問題」

一個好的探究問題有幾個特徵：它是可以測量的、它的答案不是顯然已知的、它連結到你真正好奇的事情。「什麼角度的拋體飛最遠？」是好問題。「為什麼物理很重要？」不是探究問題。

探究的步驟在你的 Python 探究中對應什麼
提問「不同星球上同樣的拋體飛多遠？」
假設「我猜月球飛最遠，因為重力最小」
設計實驗改變 g 的值，其他條件（v₀, θ）固定
收集數據跑程式，記錄各星球的射程
分析射程和 g 成反比，畫圖確認
結論「射程 = v₀²sin(2θ)/g，g 越小射程越大」
延伸問題「如果初速度也不同呢？太陽表面呢？」

控制變量：讓比較有意義

比較不同星球的拋體時，你只改變 g（重力加速度），v₀ 和 θ 保持不變。這叫「控制變量」——確保你觀察到的差異，真的是因為你想測試的那個因素造成的，而不是其他原因。

這是整個實驗科學方法的核心。如果你同時改了 g 也改了 v₀，你就無法知道是哪個造成差異。

練習：批判一個壞實驗
批判思考 題目 1
小明想測試「喝能量飲料是否提升反應速度」。他喝了能量飲料之後，做了反應速度測試，結果比昨天快了 0.05 秒。他說：「有效！能量飲料讓我反應更快。」這個實驗的問題在哪裡？你會怎麼改進？
至少三個問題：沒有對照組、沒有控制其他變量、樣本太小（只測一次）。
改進方式：（1）設對照組：同樣時間喝安慰劑（外觀相同但無成分的飲料），看反應速度是否也提升；（2）控制其他變量：確保睡眠、食物、測試時間相同；（3）多次測試取平均；（4）讓測試者不知道自己喝的是哪種（盲測）。科學實驗必須排除「其他解釋的可能性」，才能確定因果關係。

主題 B骰子真的公平嗎？
主題 B 的知識背景：大數法則與機率

機率是「長期頻率」的預測，不是每次的保證

擲一顆公平骰子，每面出現的機率都是 1/6 ≈ 0.167。這不是說「每 6 次一定各出現一次」，而是說「擲非常非常多次之後，每面的比例會趨近 1/6」。這就是大數法則。

大數法則（雅各布·伯努利，1713）
當 n → ∞，實際頻率 → 理論機率
n 次試驗中，事件 A 發生 k 次，則 k/n 隨著 n 增大，會越來越接近 P(A)（事件 A 的理論機率）。
但注意：「接近」不是「等於」——就算擲 100 萬次，各面也不會完全相等，只是非常接近。

標準差：量化「偏差」

如果每面理論機率是 p = 1/6，n 次試驗後，各面出現比例的標準差（不確定度）約為 √(p(1−p)/n)。

n = 10 時，標準差約 ±0.149（很大的偏差是正常的）。n = 10000 時，標準差約 ±0.0047（非常接近 1/6）。這就是「擲越多次越準」的數學依據。

延伸：賭場如何靠大數法則賺錢
  • 輪盤有 0 和 00（美式），讓銀行有 5.26% 的優勢（house edge）
  • 每一局，賭客有可能贏；但長期下來，大數法則保證賭場必然獲利
  • 這就是為什麼「系統性賭博策略」長期無法打敗賭場——除非能預測隨機結果
  • MIT 的「黑傑克小組」是真實故事：他們用「記牌」（不是隨機！）系統性地改變機率，打敗了拉斯維加斯
計算 B-1
擲 1000 次骰子，理論上「6」應該出現幾次？如果實際出現了 180 次，這正常嗎？（提示：計算標準差 σ = √(np(1−p)) ）
理論期望 ≈ 167 次，標準差 ≈ 11.8。180 次在 1 個標準差之內，算正常。
期望次數 = 1000 × 1/6 ≈ 166.7。σ = √(1000 × 1/6 × 5/6) = √138.9 ≈ 11.8。180 − 167 = 13，約 1.1 個標準差，這在統計上很正常（68% 的情況都在 1 個標準差內）。
主題 C我的足球飛多遠？
主題 C 的知識背景：測量、誤差與模型的限制

模型 ≠ 現實：誤差的三個來源

你的 Python 程式是「理想模型」——沒有空氣阻力、球是質點、地面是平的。現實中的足球有三個主要誤差來源：

誤差來源影響方向大小估計
空氣阻力讓球飛得更近可達理論射程的 20–40%
旋轉效應（馬格努斯力）讓球曲線飛行視旋轉速度而定
角度測量誤差射程敏感地依賴角度5° 誤差可導致 10% 射程誤差

香蕉球的物理：馬格努斯效應

足球繞著自身旋轉時，一側的空氣被「帶動」加速，另一側被減速。根據白努利定理（快速流動的流體壓力較低），壓力差造成球朝特定方向偏轉——這就是足球的「香蕉球」、棒球的「變化球」、網球的「上旋球」。

延伸：為什麼真實彈道比模擬複雜得多
  • 空氣阻力正比於速度的平方（速度越快，阻力增加四倍），而不是速度本身
  • 在海平面和高海拔（例如高原），空氣密度不同，同樣踢法射程不同（這就是為什麼高原球場容易踢出好成績）
  • FIFA 世界盃中，2010 年南非比賽用的 Jabulani 球因為氣流不穩定，守門員難以預測，引起很大爭議
應用 C-1
你測量自己踢球的距離是 30 公尺，估計角度是 30°。（a）用公式反推初速度。（b）如果角度其實是 35°（你測量有誤差），真正的初速度應該是多少？兩者差距多大百分比？
（a）v₀ ≈ 18.5 m/s　（b）v₀ ≈ 17.0 m/s，差距約 8.1%
（a）v₀ = √(30×9.8/sin(60°)) = √(294/0.866) = √339.5 ≈ 18.4 m/s
（b）v₀ = √(30×9.8/sin(70°)) = √(294/0.940) = √312.8 ≈ 17.7 m/s
差距：(18.4−17.7)/18.4 ≈ 3.8%（實際計算可能因精確值略有不同）。5° 的角度誤差導致約 4% 的速度計算誤差——這說明角度測量的準確度很重要。
思考 C-2
你的程式模擬假設沒有空氣阻力，但真實足球有。如果程式計算出射程 40 公尺，你實際踢的球可能落在幾公尺？說明你的推理。
可能落在 24–34 公尺之間（約縮短 15–40%）
空氣阻力讓球損失能量，射程會比理想模型短。對於一般強度的踢球（初速 15–25 m/s），空氣阻力造成的射程損失約 15%–40%，取決於球的旋轉、風速等因素。這就是「模型的限制」——即使數學完全正確，現實也會不同。好的科學家不會說「模型錯了」，而是說「模型有哪些假設，這些假設在什麼情況下成立或不成立」。
